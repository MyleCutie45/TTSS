
## MANDATORY WORKLOG REQUIREMENT

Before starting:

1. Read CLAUDE.md.
2. Read WORKLOG.md.
3. Review the latest development history.
4. Understand the current project status.

During development:

- Explain your implementation decisions.
- Record meaningful changes in WORKLOG.md immediately.
- Do not postpone documentation until the end.
- Record actual commands, tests, errors, and results.

Before finishing:

1. Update WORKLOG.md.
2. Update the Current Development Summary.
3. List all modified files.
4. Explain what was accomplished in beginner-friendly language.
5. Explain what remains unfinished.
6. Recommend the next task.

This requirement applies even if the task is small.
