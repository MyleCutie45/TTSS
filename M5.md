
We are starting Milestone 5: Performance Optimization.

Act as a senior C++ performance engineer.

Analyze the existing profiling and benchmark results before changing the code.

Investigate the following optimization opportunities:

1. Reduce repeated memory allocations.
2. Improve memory locality.
3. Minimize unnecessary image copying.
4. Optimize OpenMP parallel region management.
5. Investigate static, dynamic, and guided scheduling.
6. Reduce synchronization overhead where correctness permits.
7. Investigate cache-friendly memory layouts.
8. Optimize DP matrix access.
9. Investigate whether the energy map can be updated locally after seam removal instead of recomputing everything.

For every optimization:

- Explain the bottleneck.
- Explain the proposed solution.
- Implement it separately.
- Run correctness tests.
- Benchmark against the previous implementation.
- Record whether it improves performance.

Do not sacrifice algorithmic correctness for speed.

Maintain a clear distinction between:

- Original sequential algorithm.
- Basic OpenMP implementation.
- Optimized OpenMP implementation.

Create docs/optimization_report.md.

Only retain optimizations supported by actual benchmark evidence.
