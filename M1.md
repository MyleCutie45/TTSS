
We are starting Milestone 1: Sequential Seam Carving Implementation.

Read the existing project documentation before writing code.

Implement a complete sequential Seam Carving algorithm in C++17.

Requirements:

1. Load an image using OpenCV.
2. Convert the image into an appropriate format.
3. Calculate the energy map using the gradient-based energy function from the original paper.
4. Implement cumulative energy calculation using dynamic programming.
5. Find the minimum-energy vertical seam.
6. Backtrack to reconstruct the seam.
7. Remove the seam while preserving image structure.
8. Repeat until the target width is reached.
9. Save the resulting image.
10. Support configurable input and output paths and target dimensions.

Technical requirements:

- Use clear and readable C++.
- Separate energy calculation, dynamic programming, seam finding, and seam removal into functions.
- Correctly handle image boundaries.
- Avoid unnecessary memory allocations.
- Do not use OpenMP yet.
- Implement vertical seam removal first.
- Horizontal resizing can be added by transposing the image or using a separate implementation.

Testing:

- Test small images manually.
- Verify the output dimensions.
- Verify seam connectivity.
- Verify that exactly one pixel is removed from each row per iteration.
- Test edge cases.

Do not implement parallelization yet.

After implementation:

1. Build the project.
2. Run tests.
3. Fix compilation errors.
4. Explain every major function.
5. Provide commands to execute the program.
6. Update README.md.
