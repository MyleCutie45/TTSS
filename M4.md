
We are starting Milestone 4: Performance Benchmarking.

Act as a parallel performance engineer.

Build a reproducible benchmark system comparing sequential and OpenMP implementations.

## 1. Test configurations

Image resolutions:

- 512x512
- 1920x1080
- 3840x2160
- 7680x4320 (if hardware resources allow)

Resize targets:

- Remove 10% of original width.
- Remove 20% of original width.
- Remove 30% of original width.

Thread configurations:

- 1
- 2
- 4
- 8
- 16

Only test thread counts supported by the machine.

## 2. Benchmark metrics

Measure:

- Total execution time.
- Energy calculation time.
- Dynamic programming time.
- Seam finding time.
- Seam removal time.
- Speedup.
- Parallel efficiency.

Use:

Speedup(p) = T_sequential / T_parallel(p)

Efficiency(p) = Speedup(p) / p

## 3. Experimental methodology

- Exclude image loading and saving from the core algorithm timing.
- Ensure sequential and parallel implementations perform identical work.
- Run each configuration multiple times.
- Report median and variability.
- Record CPU model, core count, logical processor count, compiler, compiler flags, OpenMP version, and image resolution.
- Avoid comparing runs with different hardware conditions.
- Distinguish initialization overhead from steady-state execution.

## 4. Benchmark output

Save results as CSV.

Create Python scripts using Matplotlib to generate:

1. Execution time vs thread count.
2. Speedup vs thread count.
3. Efficiency vs thread count.
4. Runtime breakdown by algorithm component.
5. Performance comparison across image sizes.
