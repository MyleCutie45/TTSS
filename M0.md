
# Project: Parallel Implementation of Seam Carving using OpenMP

You are a senior C++ developer and parallel computing engineer. Act as the technical lead for this university Parallel Computing project.

## 1. Project Objective

Implement the Seam Carving algorithm for content-aware image resizing based on the original paper:

"Seam Carving for Content-Aware Image Resizing"
Shai Avidan and Ariel Shamir, 2007.

The primary objective is to investigate how OpenMP can accelerate the algorithm on multicore CPUs.

This is an academic parallel computing project. Algorithmic correctness, parallelization methodology, performance evaluation, and clear explanations are more important than building a sophisticated GUI.

## 2. Technology Stack

- C++17
- OpenMP
- CMake
- OpenCV for image input/output
- Python and Matplotlib for benchmark analysis and visualization

## 3. Implementation Requirements

We need separate implementations:

1. Sequential baseline.
2. OpenMP Energy Map implementation.
3. OpenMP Dynamic Programming implementation.
4. OpenMP Seam Removal implementation.
5. Combined OpenMP implementation.

The sequential and parallel implementations must produce equivalent results.

## 4. Development Rules

- Do not implement the entire project immediately.
- Work incrementally through milestones.
- Explain the algorithm before implementing it.
- Use readable C++ code suitable for undergraduate students.
- Avoid unnecessary abstractions and complicated design patterns.
- Keep sequential and parallel implementations clearly separated.
- Do not introduce parallelism where data dependencies make it incorrect.
- Avoid unnecessary memory allocation and copying.
- Handle image boundaries correctly.
- Use reproducible benchmarking methodology.
- Never fabricate benchmark results.

## 5. First Task: Research and Architecture

Do NOT write implementation code yet.

First:

1. Explain the original Seam Carving algorithm.
2. Explain its computational complexity.
3. Identify independent computations that can be parallelized.
4. Explain the dependencies in dynamic programming.
5. Propose OpenMP parallelization strategies.
6. Identify potential race conditions and synchronization requirements.
7. Propose a project directory structure.
8. Design the testing and benchmarking methodology.

Create:

Write documentation in clear English, with mathematical formulas, pseudocode, and practical examples.
