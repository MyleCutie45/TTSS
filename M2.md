
We are starting Milestone 2: OpenMP Parallelization.

Read the sequential implementation and all project documentation.

Our goal is to parallelize the existing implementation while preserving algorithmic correctness.

Implement the following stages separately:

## A. Parallel Energy Map

Use OpenMP parallel for to distribute pixel-level energy calculations.

Each pixel calculation should be independent.

## B. Parallel Dynamic Programming

Implement row-wise parallel dynamic programming.

Important dependency:

M(x,y) depends on M(x-1,y-1), M(x,y-1), and M(x+1,y-1).

Therefore:

- Pixels within the same row can be calculated concurrently.
- Different rows cannot be calculated independently.
- Ensure synchronization between consecutive rows.
- Avoid race conditions.

Investigate whether a persistent parallel region with appropriate synchronization can reduce parallel region overhead.

## C. Parallel Minimum Endpoint

Use OpenMP reduction or another appropriate parallel reduction strategy to identify the minimum cumulative energy in the last row.

Ensure deterministic tie-breaking.

## D. Parallel Seam Removal

Parallelize pixel shifting across independent image rows.

Ensure there are no overlapping writes between threads.

## E. Combined Implementation

Integrate the parallel components into a complete OpenMP version.

Requirements:

- Keep the sequential implementation unchanged as the reference.
- Allow configurable thread counts.
- Support OpenMP scheduling experiments.
- Avoid unnecessary critical sections.
- Document synchronization points.
- Explain which sections remain sequential and why.

Do not optimize prematurely.

First establish correctness, then investigate performance.

After implementation:

1. Build with OpenMP enabled.
2. Run correctness tests.
3. Compare sequential and parallel outputs.
4. Run tests with 1, 2, 4, and 8 threads where available.
5. Document parallelization decisions and limitations.
